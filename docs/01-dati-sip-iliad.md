# Passo 1: recupera i dati SIP della linea Iliad

Per il trunk servono tre dati che Iliad assegna alla tua linea fissa: utente, password e server. Tienili riservati e non pubblicarli mai in chiaro.

- Utente: il numero fisso completo, con lo 0 iniziale (per esempio `0XXXXXXXXXX`).
- Password: quella generata da Iliad per la linea.
- Server: `voip.iliad.it`, porta 5060, protocollo UDP.

Cerca i dati nell'area personale Iliad, nella sezione della linea fissa, alla voce per configurare un telefono o un dispositivo VoIP. Il nome della voce può cambiare nel tempo: se non la trovi, chiedi all'assistenza Iliad.
